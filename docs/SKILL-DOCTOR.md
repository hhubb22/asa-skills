# skill-doctor 使用

复盘一组实际任务，决定指令是否应该修改。一次运行完成一次分析，不会自动创建日程、扫描全部历史或持续监听。

## 直接复盘

在 Agent 中明确指定当前会话或已选定的导出材料，并说明只建议还是同时应用经检查的修改。已有材料和权限足够时直接分析，不再逐项确认；没有历史时可做静态审计，但不能得到行为改进结论。

报告使用任务证据定位问题，先核对实际加载的版本，区分规则、触发、模型与环境的责任。默认只生成报告、候选文件与 diff。apply 是另一个授权范围，不是自动后续动作。

## 可选的离线整理

在库根目录可以用合成材料试验，不接触真实日志：

```bash
python3 skills/skill-doctor/scripts/collect_sessions.py \
  --input evals/fixtures/synthetic-session.txt \
  --out /tmp/asa-skill-doctor-demo
```

目标目录必须尚不存在。真实材料改为明确的文件路径，可以重复 --input；不会扫描目录。支持人工整理的 UTF-8 .md/.txt，以及 Codex、Pi、Claude 和通用 role/content JSONL 的已实现记录子集。可用 --format 显式指定。未知格式需要经过人工确认的文本导出，不假装所有宿主日志版本都兼容。

默认每文件最多读取 10 MiB，全部输入最多 50 MiB；每文件保留最多 80,000 个可见字符。--max-chars 可以调整但上限为 500,000。裁剪量和跳过记录数在 inventory.json 中列出；截断样本不能当成完整会话。

输出包含经过启发式脱敏的 session-001.md 等文件、来源摘要和原始文件 SHA-256。工具不评分、不调用模型、不上传、不复制原始文件。输出目录权限 0700、文件权限 0600 在 POSIX 上设置。

**启发式脱敏不完整，本地收集不等于本地推理。**在云模型读取前核对组织政策并人工检查公司代码、个人信息、地址和自定义密钥。需要数据不出机器时使用获准的本地模型或更小的手工脱敏摘要。

## 验证改动

基线与候选使用相同模型、宿主、任务、代码基线及权限；在新工作区重跑。先用导致问题的案例检查修正，再用未参与修改的案例检查误触发和回归。没有执行就报告 not_run，有混杂因素就报告 inconclusive。

参考 [evals](../evals/README.md) 准备案例。不要把 prepare_eval、结构检查或收集器测试的通过写成 Astra 的行为通过率。不要为了本次结果变好去修改判分标准。

没有足够依据、无需增加规则，或者应该修代码/工具，都是有效结论。指标不是 skill 调用数量，也不是报告篇幅。
