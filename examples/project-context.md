# 可选的项目接入提示

这不是需要自动安装的 AGENTS.md。只将确实适合项目的几句合入现有入口，不要求每个仓库新增全部文件。

- 调查、设计、审查默认不改产品代码；明确要求实施时，在既定范围内完成必要验证和修复。
- 存在重要语义或兼容性决策时提出证据与修订；既有授权不在每个阶段重问。
- 模块知识使用本项目已有的文档；技术设计写在哪里、测试入口是什么，应指向真实位置，不引用不存在的示例文件。
- 需要跨多个步骤时可使用 work；明确任务可直接选择对应 skill，小任务可以不加载专用流程。

共享设备、外部系统和发布权限写项目真实限制，并由宿主权限落实。不要为了采用本库放宽这些限制。
