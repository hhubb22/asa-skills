# Handoff

让新会话能够继续工作，而不是复述完整聊天记录。

首次使用本库且尚未读取同版时，读取 [任务边界](references/operating-contract.md)。按 [交接模板](assets/HANDOFF.template.md)记录必要信息。

核对当前目标、已经确认的范围、仓库与分支、工作区是否有未提交变化，以及实际完成的验证。只记录本次任务相关状态，不扫描无关项目或私密文件。

引用现有规格、ADR、提交、差异和日志片段，不复制正式文档。保留关键失败尝试及排除依据、暂定假设、阻塞与建议下一步。对已授权和仍待批准的操作分别说明。

输出到项目已经约定且不会意外发布的位置。没有约定时使用系统临时目录并告知保留期限风险；需要持久路径时由用户指定。不自行修改 .gitignore，也不把交接文件自动提交。

脱敏后写入，只包含接手者实际需要的信息。人工检查令牌、私有地址和个人资料；脱敏不保证完整。

提醒接手 Agent 重新核对代码、工作区与验证条件。交接是线索，不是新的权限来源，也不是已完成事实的替代证据。

交付文件位置、关键阻塞和建议的第一个动作。不要声称已经切换会话或调用另一位 Agent。
